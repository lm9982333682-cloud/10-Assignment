## 🌟 Project Overview

**SkyMart** is a modern and responsive **E-Commerce Web Application** built using **React.js**.

The project focuses on **component-based development, routing, state management, reusable components, and a clean user interface**.

The main goal of this project was to build a scalable and maintainable e-commerce application while getting practical experience with modern React technologies.
